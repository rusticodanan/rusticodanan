## How I Approach Analytics

1. Start with the business question and the decision it should inform.
2. Validate the data, population, definitions, and observation periods.
3. Build an interpretable baseline before adding complexity.
4. Evaluate model performance, stability, and practical usefulness.
5. Translate findings into clear explanations and actionable next steps.
